# Matrakka · Proyecto Abarrotero

Sitio web oficial de **Proyecto Abarrotero Matrakka, S.A. de C.V.**

Abasto integral de abarrotes al mayoreo y menudeo para el comercio de la Ciudad de México.

## Líneas de producto

- Abarrotes y enlatados
- Lácteos, quesos y embutidos
- Frutas, verduras y raíces
- Semillas y granos
- Bebidas, jugos y agua
- Higiene, limpieza y jarcería
